# Fake News Detection

A machine-learning web app that classifies news articles as **real** or **fake**. Paste in an article and the model returns a prediction with a confidence score. Built as a major academic project.

🔗 **Live demo:** https://fake-news-detection-major-project.vercel.app

---

## ✨ Features

- Classifies news text as real or fake in real time
- Confidence score for each prediction
- NLP text preprocessing (cleaning, tokenization, vectorization)
- REST API backend serving the trained model
- Clean, responsive React frontend

---

## 🛠 Tech Stack

- **Machine Learning:** Python, scikit-learn, NLP
- **Backend:** Python (REST API)
- **Frontend:** React
- **Hosting:** Vercel

---

## 📁 Project Structure

- `backend/` — Python API and the trained ML model
- `frontend/` — React client for entering text and viewing results

## ⚙️ Getting Started

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend

```bash
cd frontend
npm install
npm start
```
